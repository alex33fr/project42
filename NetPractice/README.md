# NetPractice

## Description

NetPractice is a project from the 42 school whose objective is to discover the basics of networking
through simulated networks. Each level shows a network that does not work, and the goal is to fix it
by setting the right IP addresses, subnet masks and routes on hosts and routers.

## Instructions

To use the script, download the net_practice.1.9 archive attached to the project page and extract it.
Then, from the extracted folder, run this shell command:

```bash
./run.sh
```

The script starts a local web server and opens the training page in your browser.

Then go to http://localhost:49242 in your browser.
